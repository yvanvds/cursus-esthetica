# slidev — projectskill

`SKILL.md` beschrijft hoe de decks van deze cursus gebouwd worden. Die tekst is
projecteigen en staat in de repo.

`references/` is upstream Slidev-documentatie, oorspronkelijk gevendord via
`npx skills add slidevjs/slidev`. Ze is gesnoeid tot wat hier van toepassing is;
zestien bestanden over developer-features zijn verwijderd:

```
code-groups            editor-monaco          diagram-plantuml
code-import-snippet    editor-monaco-run      presenter-notes-ruby
code-line-highlighting editor-monaco-write    syntax-comark
code-line-numbers      editor-prettier
code-magic-move        editor-side
code-max-height        editor-vscode
code-twoslash
```

Haal je de skill opnieuw op bij upstream, snoei dan opnieuw en laat `SKILL.md`
staan — die is niet van hen.
